# Fibre and stalk evaluation

This umbrella exposes finite-closed neighborhood evaluation, explicit normalization-relative
stalk adapters, literal constant point fibres, and positive-degree wrappers supplied by the
proved resolution/Ext presheaf normalization. No proper-base-change theorem is asserted.
