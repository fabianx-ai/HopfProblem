## Tool notes

* `git merge-tree --write-tree p1 p2` followed by `git diff <tree> <merge>` is a complete, mechanical check that a merge changed only conflicted regions; the receipt could include the one-line result ("diff against auto-merge touches only: …") per merge, which would have made findings 3 and the "nothing dropped" claim verifiable without a clone.
* `envdiff.py` is deterministic and cheap; the receipt's bucket counts should be produced by a script (name-prefix rules as in this review) rather than by hand — both wrong sub-counts (findings 1, 2) are hand arithmetic.
* The after dump produced with `--rename` stores base names, so `envdiff.json` names are base coordinates; the receipt should say so explicitly (I lost time on "key not in after environment" before realising). A rename map containing both orientations (dfiles-a) should be normalised before concatenation.
* `envdiff.txt` truncates every list at 20 entries; the full lists are only in the JSON. A `--all` listing or a per-bucket reconciliation file beside the receipt would make the 221 auditable by eye.
