## Tool notes

- `split_module.py` loses an `attribute … in` prefix when a blank line or a `/-! -/` header sits between it and the declaration, and its per-unit SHA receipt cannot see the loss. A check of the complement (base lines not covered by any unit) would have caught it; the cross agent did that by hand, the prism agent did not.
- `envdiff` classes a universe lift as `PROOF-NAMING` and reports `changed_type_source 0` for the 11 lifted statements. The class name hides real statement changes; lifts need their own class.
- The dump's ranges exclude a leading `… in` prefix and include the docstring; block comparison by range therefore needs a separate line-level pass for prefixes, `open`, `variable` and `universe` lines.
- `envdiff.txt` prints only the first 20 `PROOF-NAMING` names; the full 34 are in `envdiff.json`.
